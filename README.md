# C Day 101 – Employee Payroll & Tax Management

## Description
A C programming project that manages employee salary records and calculates payroll using allowances, deductions, and simplified tax rules.

## Features
- Add employee records.
- Read employee data from a file.
- Calculate gross salary.
- Calculate deductions and estimated tax.
- Generate net salary reports.
- Calculate total payroll.

## Files
- `payroll.c` – Main C program.
- `employees.txt` – Sample employee database.

## How to Compile
```bash
gcc payroll.c -o payroll
```

## How to Run
Windows:
```bash
payroll.exe
```

Linux:
```bash
./payroll
```

## Concepts Used
- Structures
- Functions
- File Handling
- Conditional Statements
- Salary Calculations
- Record Processing

## Note
Tax percentages are simplified educational assumptions, not official tax calculations.
